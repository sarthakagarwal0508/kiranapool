# KiranaPool Demo Seed

This seed creates synthetic Jaipur demo data for the existing Mongoose schemas and dashboard flows.

## Run

From the `backend` folder, make sure `.env` points to a **demo/test MongoDB database**, then run:

```bash
npm run seed:demo
```

It is safe to re-run for the same demo wholesaler: generated demo orders, plans and forecasts for that wholesaler are rebuilt. It does not delete unrelated users, shops, or orders. Still, do not run it against production.

## Demo accounts

All accounts use the demo-only password: `KiranaDemo@123`

- Wholesaler: `demo.wholesaler@kiranapool.test`
- Shopkeepers: `demo.shopkeeper1@kiranapool.test` through `demo.shopkeeper10@kiranapool.test`
- Riders: `demo.rider@kiranapool.test`, `demo.rider2@kiranapool.test`, `demo.rider3@kiranapool.test`

## Seeded features

- 1 wholesaler and 2 warehouses
- 10 shopkeeper accounts and shop profiles across Jaipur areas
- 3 rider accounts/profiles
- 28 days of synthetic delivered order history for forecasting/trends
- Upcoming pending orders in shared time windows for pooling previews
- One planned pooled route assigned to a rider and one picked/in-progress order
- Seven days of shop-level and area-level demo forecast rows for dashboard charts

Forecast rows with `modelSource: "demo-seed"` are mock display data, not predictions generated by the ML service. When testing real ML integration, use the forecast-generation endpoint and check its returned `modelSource`.

## Important

These are fictional demo accounts and synthetic data. Do not use the credentials in production or expose the demo database publicly.
